# blueprint/dogfood-session - run log

## Learnings (evidence discipline)

1. **Steps before the fix.** A repro evaporates once the bug is
   fixed; record steps + expected + actual at finding time.
2. **Closed severity set.** blocker/major/minor/nit via classify -
   verbatim labels keep the report sortable.
3. **Blocker alerts once.** The alert-once record dedupes the
   notify; the session records feed the weekly review.
