# blueprint/weekly-review - run log

## Learnings (receipts live-verified; task/event/summarise suite-tested)

1. **Failed tasks are the review's gold.** The result field carries
   what was tried and what broke; done tasks alone flatter the week.
2. **Cancelled events are news too.** The record says what was
   retracted - the review reads both notified and cancelled.
3. **The review is only as true as the receipts.** Store round-trips
   were live-verified (grocery, workout, digest scenarios); work that
   never wrote a receipt stays invisible to the review.
4. **Chain the notes.** Each review reads the previous plan and
   answers it - the chain is the agent's durable self-assessment
   across fresh contexts.
